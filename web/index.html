sequent

the run that never gaps — a clickable playground

Repo Design API docs

sequent turns an instant into the next document number — INV-2026-00042, then INV-2026-00043, never a gap, reset each year. A Format is a validated template (INV-{year}-{seq:05}) plus a reset policy and a timezone. Allocate derives the period key from the instant, asks a Store for the next counter under that (tenant, series, period), and renders the template — one call, one number. The counter restarts at 1 whenever the period rolls over, because the reset simply falls out of the key.

Gaplessness is a durability property, not a formatting one: a number is only truly gapless when it is allocated in the same committed transaction as the document it numbers. sequent owns the deterministic parts and leaves the atomic increment to your database. Everything below runs in your tab over the pure library compiled to WebAssembly — no backend, no network. Each ledger keeps its own counter for the session; reload to reset. Scope isolation — two tenants, one instant, no collision

One Store, two scopes. Both sides allocate the same template at the same instant, yet each starts at 1 and neither ever touches the other, because the Store key carries the tenant and series. The key is length-prefixed (4:acme3:INV4:2026), so no tenant — however adversarial, even one containing the delimiter — can merge two runs into one.

Period reset — advance the clock across the boundary

Allocate a few numbers, then step the clock forward. When the civil period rolls over — the year under Yearly, the month under Monthly, the day under Daily — the counter falls back to 1. There is no reset code: the period key changed, so the Store hands out a fresh counter. The template shows the period so you can watch it roll.

Timezone — which year is this invoice in?

"Which year is this invoice in" is a civil-date question, so the period follows the Format's timezone, not the server's wall clock. A Format built in UTC reads the instant in UTC before it picks the year. An instant just after midnight in Tokyo is still the old year in UTC — so it belongs to the old year's run.
